## 未在本次发布重新验证

- 真实手表与 iPhone 上的首次绑定、完整录音传输、断连恢复和多文件同步。
- 长时间录音、息屏/后台录音、物理快捷键、耗电及各型号/固件兼容性。
- 使用真实后端凭据进行转写和纪要生成。
- iPhone 与 HarmonyOS 正式发布签名、App Store / AppGallery 商店审核。

模拟器不提供真实手表 BLE 验证。本次没有安装或操作用户的实体设备。
早期内部产品曾进行真机开发，但旧记录不能代替此公开候选版本的实机验收。
因此首版标为 alpha 源码发布，先从短录音和明确的设备组合验证起。
