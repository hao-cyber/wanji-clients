# 公开源码版的数据处理

这是客户端行为说明。自行部署或分发时，应按自己的应用、服务和实际处理行为
提供隐私说明；本文件不代表任意第三方后端的政策。

- 手表录音先写入手表本地队列，通过绑定后的 BLE 链路交给手机。
- 手机将收到的音频保存到应用本地目录，供播放、导出与用户主动发起的处理。
- 公开 iOS 构建没有默认服务地址。未配置兼容后端时，本地录音和同步仍可使用。
- 远程转写/纪要会把所选录音发送到使用者配置的服务。服务令牌保存在 iOS Keychain。
- 从外部链接导入服务配置时，会先展示目标服务器；确认之前不更换地址或令牌。
- 传输或远程处理失败时，本地音频保留供重试。手机确认接收前不能将手表副本视为已安全送达。
- 应用的调试日志可能包含录音标识、大小、时间和蓝牙设备信息。分享前应脱敏。
- 仓库不包含录音、个人账号、私有服务实现或签名证书。

HarmonyOS 客户端的现有隐私页还标有原产品的在线政策地址；它不是此开源版本的
默认音频服务，也不会因此自动上传录音。自行分发前，应将该静态说明更新为
发行者自己的政策，并在目标设备上验证布局和权限流程。

录音前请取得参与者同意。删除应用或更换签名可能清除本地数据，先导出需要保留的录音。

## 蓝牙配对边界

从 `v0.1.0-alpha.2` 起，Android 手表只向当前已通过连接令牌鉴权的蓝牙连接发送录音。
另一连接读取队列或开启通知不会因此获得录音访问权限。已有绑定不能用新的令牌远程覆盖；
原手机使用同一令牌重复绑定仍然可用。

Android 首次绑定尚未增加手表上的确认步骤，也没有独立的本机解绑界面。
更换手机前应先同步或导出需要保留的录音；请勿通过清除应用数据来处理尚未同步的录音。
HarmonyOS 绑定继续要求在手表上打开限时配对窗口。

当前协议未强制要求系统级加密配对。连接令牌检查不能替代蓝牙链路加密，
此 alpha 版本尚未完成附近设备抢先配对、窃听和主动中间人攻击的防护验收。
